## 2. Investigation Objective

Investigate repeated failed `sudo` authentication attempts on a monitored Ubuntu Server endpoint and validate Wazuh's ability to detect potentially suspicious privileged-access activity.

The investigation focuses on authentication failures, security alert generation, event analysis, and MITRE ATT&CK classification.

## 3. Detection Summary

A controlled authentication-failure test was conducted on the Ubuntu endpoint.

The test generated three incorrect password attempts while validating `sudo` credentials.

Wazuh detected the event using its built-in Rule `5404`.

**Alert Description:** Three failed attempts to run sudo.

**Alert Severity:** Level 10.

## 4. Test Procedure

The following commands were executed on the monitored Ubuntu endpoint:

```bash
sudo -k
sudo -v
```

Three intentionally incorrect passwords were entered during the `sudo -v` authentication prompt.

The terminal displayed:

```text
sudo: 3 incorrect password attempts
```

The test did not execute a privileged command or demonstrate successful privilege escalation.

## 5. Log Analysis

The Ubuntu system journal recorded the authentication failure.

The relevant Wazuh alert contained:

```text
socadmin : 3 incorrect password attempts ;
TTY=tty1 ; PWD=/home/socadmin ;
USER=root ; COMMAND=validate
```

**Log Source:** journald

**Program:** sudo

**Event Time:** October 19, 2026, 03:44:52 (VM log time)

The event identifies the account attempting authentication, the requested privileged user, and the authentication failure.

## 6. Wazuh Alert Investigation

Wazuh successfully collected the event from the Ubuntu endpoint and generated a Level 10 alert.

## 7. MITRE ATT&CK Mapping

| Field | Mapping |
|---|---|
| Technique ID | T1548.003 |
| Technique | Sudo and Sudo Caching |
| Tactics | Privilege Escalation, Defense Evasion |

The alert is mapped to the MITRE ATT&CK technique associated with abuse of elevated privileges through `sudo`.

This mapping provides investigation context but does not establish that a real privilege escalation attack occurred.

## 9. Investigation Findings

- Three incorrect `sudo` password attempts were generated during an authorized test.
- Ubuntu recorded the authentication failures in the system journal.
- Wazuh Agent `001` forwarded the relevant event to the Manager.
- Built-in Rule `5404` generated a Level 10 security alert.
- The alert was associated with MITRE ATT&CK technique T1548.003.
- No successful privilege escalation was demonstrated during the failed-authentication test.

## 10. Recommended Security Controls

- Monitor repeated failed `sudo` authentication attempts.
- Apply least-privilege principles to administrative accounts.
- Review membership in privileged Linux groups.
- Investigate unexpected privileged command execution.
- Maintain centralized authentication logging and alert monitoring.

## 11. Investigation Conclusion

The investigation confirmed that Wazuh successfully detected repeated failed `sudo` authentication attempts on the monitored Ubuntu endpoint.

The event was generated intentionally as part of an authorized SOC laboratory experiment.

**Final Classification:** Authorized Security Test — No Confirmed Compromise.

**Investigation Status:** Closed.
