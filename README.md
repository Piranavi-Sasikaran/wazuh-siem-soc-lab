# Wazuh SIEM – SOC Monitoring & Threat Detection Lab

## Project Overview
This project demonstrates the implementation of a hands-on Security Operations Center (SOC) lab using Wazuh SIEM for centralized log collection, security monitoring, threat detection, and incident investigation.

The lab is designed to simulate real-world security events and develop practical Blue Team and SOC analyst skills.

**Project Status:** In Progress (~35% Complete)

## Technologies Used
- Wazuh SIEM
- Ubuntu Linux
- Windows 11 (Host OS)
- SSH
- Linux authentication logs

## Completed Work
### 1. SIEM Environment Setup
Established a Wazuh environment for security event monitoring.

### 2. Endpoint Monitoring
Configured an Ubuntu endpoint (`ubuntu-soc-agent`) and verified security log collection.

### 3. SSH Authentication Attack Simulation
Generated suspicious SSH authentication activity in a controlled lab using an invalid username.

### 4. Security Event Analysis
Observed SSH events in Wazuh and examined the source IP, username, service, and raw log messages.
